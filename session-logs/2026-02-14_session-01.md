### 8. Stage 1 Built — Full OpenCV App

Installed dependencies: `opencv-contrib-python 4.13.0`, `pygame 2.6.1`, `mediapipe 0.10.32`, `numpy`

Built 7 source files:
- `src/config.py` — Constants (display dims, colors, thresholds)
- `src/camera.py` — C922 auto-detection and capture
- `src/hand_tracker.py` — MediaPipe hands, pinch gesture detection
- `src/projector.py` — Pygame fullscreen rendering on AAXA P7+
- `src/calibration.py` — 4-point homography (camera→projector mapping), save/load JSON
- `src/ui_elements.py` — Button (hover/pinch-click), Label, Panel classes
- `src/app.py` — Main loop wiring everything together

**Design decisions:**
- Pinch gesture (thumb+index) for clicking (user chose this over dwell)
- Debug view on laptop screen (camera feed + hand landmarks)
- Projected UI: title bar, 4 buttons (Calibrate, Clear, Mode: Design, Mode: Build), content panel, status bar, hand cursor
- Calibration: project 4 dots, user pinches each, homography computed
